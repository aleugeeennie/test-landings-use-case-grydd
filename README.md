# GRYDD landings completas

Este paquete incluye las landings completas solicitadas:

- `index.html`
- `freight-forwarders.html`
- `enterprise-shippers.html`
- `thankyou.html`
- `styles.css`
- `script.js`
- `assets/favicon.png`
- `assets/icon-grydd.png`
- `assets/logo-grydd.png`
- `assets/logo-grydd-white.png`

Cambios aplicados:

1. Todas las páginas usan `assets/favicon.png` como favicon.
2. `index.html`: reviews en doble carrusel animado, con foto en todas las cards, incluyendo la segunda fila.
3. `freight-forwarders.html`: se corrigió la card `24/7 Real-time visibility` para que no se empalme; se agregó visual derecho en About; reviews como index con doble carrusel, animación y fotos en todas.
4. `enterprise-shippers.html`: se retiró la card grande del hero; se animaron textos del hero; se agregó fondo de partículas; reviews como index con doble carrusel, animación y fotos en todas.
5. `thankyou.html`: incluida para que el paquete quede completo. Como no venía el HTML original en el zip recibido, se dejó una versión compatible visualmente con el resto del paquete.

Nota: las fotos de reviews y visuales usan URLs remotas de Unsplash para mantener el paquete ligero. Si necesitas todo 100% local/offline, descarga esas imágenes y cambia las rutas.
